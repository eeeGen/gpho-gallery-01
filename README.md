# gpho-gallery-01

Static GitHub Pages gallery for the photos in `assets/originals`.

- The grid lazy-loads `assets/thumbs/*_thumb.jpg`.
- The lightbox previews use `assets/previews/*_preview.jpg`.
- Every download link points only to `assets/originals/*.JPG`.
- Original JPG files are stored directly in the repository, not in a GitHub Release.

Deploy with GitHub Pages from the repository root on the `main` branch.
